Auth0 Self-Service Enterprise Configuration

This sample app demonstrates how to generate a one-time SSEC setup link so enterprise customers can configure their own SAML or OIDC identity provider on Auth0's hosted portal — no manual IdP onboarding required.

Log in as an organization member to generate setup links.

Login with Auth0

PoC only — In production, Auth0's Identifier First login handles org routing automatically based on the user's email domain.

How it works

1.
Authenticate

Log in as an org admin. Auth0 includes your org_id in the ID token.

2.
Generate a link

Enter a connection name and optional email domain aliases. The app calls the SSEC API to produce a one-time ticket URL.

3.
Share with IT admin

The enterprise IT admin visits the link, walks through Auth0's hosted wizard, and configures SAML/OIDC — all without your involvement.
